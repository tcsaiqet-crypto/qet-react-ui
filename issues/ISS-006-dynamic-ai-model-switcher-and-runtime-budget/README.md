# ISS-006: Dynamic AI Model Switcher & Runtime Thinking Budget

## Overview
Enables real-time discovery and dynamic in-flight switching between Google Gemini 3.7 Flash (with customizable 1k/4k/8k thinking budgets), Gemini 2.5 Flash, GPT-4o, and local deterministic engines without server restarts.
