# ISS-008: Playwright Script Viewer, Test Data Modal & Selective Execution

## Overview
Provides interactive inspection modals for generated Playwright automation scripts (`PlaywrightScriptModal.tsx`) and dual synthetic test data (`TestDataModal.tsx`), coupled with granular checkbox controls for individual or batch test case execution.
