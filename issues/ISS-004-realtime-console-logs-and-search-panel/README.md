# ISS-004: Real-Time Console Logs Inspector & Live Search Panel

## Overview
Replaces overlapping inspector drawers with a cleanly docked 3rd-pane `RightLogsPanel.tsx`, featuring live frontend/backend log stream switching, severity filter pills, instant keyword search with `<mark>` highlight rendering, auto-scroll locking, and log export.
