# F04 API and UI Exposure for Requirement Coverage

## Objective
Expose requirement categorization and coverage metrics through API and frontend views.

## API Scope
1. Add response fields for categorized requirements.
2. Add endpoint for requirement coverage summary per run.
3. Add endpoint for requirement category to test-case mappings.

## UI Scope
1. Add requirement coverage panel in Understanding/Test section.
2. Show category distribution and coverage percentage.
3. Show uncovered and low-confidence categories with warnings.

## Acceptance
1. API returns stable structured coverage payloads.
2. UI renders category coverage and traceability without ambiguity.
