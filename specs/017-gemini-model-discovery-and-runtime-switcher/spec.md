# Spec: Dynamic Model Discovery and Header Switcher

## 1. Functional Specifications
1. **Dynamic Model Discovery**:
   - Backend scans and returns candidate models with status indicators.
2. **Top-Header Switcher**:
   - Allows changing models on the fly directly from the header without opening full settings.
3. **Auto-Fallback**:
   - Auto-falls back to lower latency models if rate limits or latency spikes occur.
