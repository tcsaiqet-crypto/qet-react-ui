# Constitution 012: Progressive Agent Pipeline Rules

1. **5-Phase Progression**: Agents must execute in strict sequence: Understanding -> Test Cases -> Synthetic Data -> Playwright Scripts -> Execution & Reporting.
2. **5 Test Case Categories**: Phase 2 must produce test cases covering Positive, Negative, Boundary, Validation, and Error-Handling scenarios.
3. **Dual-Engine Synthetic Data**: Phase 3 must use schema-driven generation first with deterministic fallback, strictly maintaining non-PII compliance.
4. **Dedicated Automation Scripts**: Phase 4 must generate individual test script files per test case with Page Object Models.
