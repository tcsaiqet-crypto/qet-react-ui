# Spec 013: Live Playwright Execution, Lifecycle Controls & AI Test Intelligence

## 1. Executive Summary & Objective
This specification defines the architecture, user experience, data contracts, and AI-assisted workflows for **Live Playwright Execution, Lifecycle State Controls (Pause / Stop / Resume), Visual Evidence Capture (Positive & Negative Test Cases), Multi-Level JSON Diagnostic Reporting, and AI-Driven Test Intelligence & Automated Script Healing**.

---

## 2. Core Feature Pillars

### Feature 1: Lifecycle Controls (Pause, Stop, Proper Resume)
- **Pipeline Level Controls**:
  - Ability to pause before any sequential stage (Understanding, Test Cases, Synthetic Data, Playwright Generation, Execution & Reporting).
  - Clean stop to abort running background tasks without leaving orphan processes.
  - Resume from the exact paused stage without re-running or invalidating preceding completed stage artifacts.
- **Execution Level Controls**:
  - Ability to pause between individual test cases during batch Playwright execution.
  - Graceful stop terminating browser subprocesses and recording partial execution snapshots.
  - Resume queue from the paused test case index with continuous status streaming.

### Feature 2: Dedicated Script Generation per Test Case
- Each test case generated by the system (across Positive, Negative, Boundary, Validation, and Error-Handling categories) receives its own dedicated standalone Python Playwright script file (`tests/test_{case_id}_{slug}.py`).
- Shared Page Object Models (`pages/cfa_pages.py`), fixtures (`fixtures/conftest.py`), and test datasets (`test-data/synthetic_data.json`) are automatically linked.
- The suite is packaged into a standalone downloadable ZIP package (`playwright_automation_package.zip`).

### Feature 3: Live Playwright Runner in Headed Desktop Window
- Test cases are interactively displayed in a dedicated table with filters (All, Positive, Negative, Boundary, Validation, Error-Handling) and text search.
- Each test case has a direct **"▶ Run Live"** button that immediately launches the dedicated script in headed mode (`--headed`) in a new desktop browser window.
- Batch selection allows executing a custom subset or all test cases in sequence.
- Live terminal streams real-time standard output, pytest progress, and execution logs via WebSocket with auto-reconnect.

### Feature 4: Visual Screenshot Evidence for Positive & Negative Scenarios
- **Positive Test Cases**: Automatic full-page screenshot upon reaching happy path goal state (`{case_id}_passed.png`).
- **Negative Test Cases**: Automatic full-page screenshot capturing application error banners, rejection toasts, and validation states (`{case_id}_failed.png` or `{case_id}_rejection.png`).
- Evidence files stored in `uploads/{run_id}/artifacts/screenshots/`.
- Frontend visual gallery with thumbnail cards, case-type indicators, pass/fail status pills, and fullscreen modal with image zoom and download options.

### Feature 5: Multi-Level JSON Execution Report & Diagnostics
- Produces `multi_level_execution_results.json` organized in three distinct levels:
  - **Level 1 (Run Summary)**: Overall metrics (pass rate %, total scripts, passed/failed counts, duration, target host).
  - **Level 2 (Category & Feature Breakdowns)**: Pass rates and counts aggregated by Case Type (`Positive`, `Negative`, `Boundary`, `Validation`, `Error-Handling`) and Feature Area (`Authentication`, `Applicant Info`, `Document Upload`, etc.).
  - **Level 3 (Per-Script Detail)**: Script ID, filename, test case ID, duration, explicit `why_passed` / `why_failed` explanations, failure taxonomy classification (`selector_defect`, `timing_issue`, `application_defect`, `data_defect`, `environment_defect`, `test_defect`), root cause analysis, step traces, and logs.
- Interactive structured hierarchy viewer, raw JSON viewer, Copy JSON, and Download JSON.

### Feature 6: AI Test Intelligence, Diagnostics & Script Auto-Healing
- **AI Test Suite Analysis**:
  - Calculates Overall Test Health Score (0-100), Risk Level (Low/Medium/High/Critical), and Defect Distribution.
  - Generates executive evaluation explaining overall system stability and defect clusters.
  - Delivers per-test-case root cause explanations and actionable remediation advice.
- **AI Playwright Script Healer**:
  - Side-by-side code diff viewer comparing original test code against AI-proposed fixes.
  - Custom instruction prompt input to guide the AI repair.
  - One-click **"Apply Fix & Save Script"** writing changes to disk and updating run state.

## 3. User Experience & Navigation

```
Execution Page
├── Top Toolbar: State Badge | Pause | Resume | Stop | Run All (New Window)
├── Safety Strip: Non-production checkbox | Script reviewed checkbox | User approval checkbox
└── Tabs:
    ├── Tab 1: ▶ Live Playwright Runner & Terminal
    │   ├── Case Type Filters (Positive, Negative, Boundary, Validation, Error-Handling)
    │   ├── Filterable Test Case Table with 1-Click "Run Live" buttons
    │   └── Live Pytest Streaming Output Terminal
    ├── Tab 2: 📸 Visual Screenshot Evidence Gallery
    │   ├── Positive & Negative image cards with metadata
    │   └── Fullscreen Zoom & Download Modal
    ├── Tab 3: 📊 Multi-Level JSON Report
    │   ├── Summary cards (Pass rate %, duration, total scripts)
    │   ├── Case-type & Feature-area breakdown grids
    │   ├── Collapsible Script Diagnostic Cards (Why passed / Why failed / Root causes)
    │   └── Raw JSON inspector with Copy & Export
    └── Tab 4: ✨ AI Test Intelligence & Auto-Healing
        ├── Test Health Gauge (0-100) & Risk Level Card
        ├── Defect Classification Breakdown
        ├── Per-Case Root Cause & Remediation Cards
        └── AI Script Healer Modal (Side-by-side Diff + 1-Click Apply)
```
