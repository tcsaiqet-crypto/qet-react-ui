# Feature 022: Test Case & Synthetic Data Intelligence, Script Visibility, and Selective Execution

## Overview
Feature 022 resolves the transparency gap in the QET platform by providing:
1. **Collapsible Workspace**: Auto-collapsing and manual accordion views for document intake and codebase indexing, removing cluttered hero buttons.
2. **Dedicated Script Viewer**: An inline code modal allowing QA engineers to inspect, copy, and download the exact Python Playwright test script (`test_tc_*.py`) generated for each scenario.
3. **Synthetic Test Data Inspector**: An inline modal displaying the sanitized mock datasets mapped to each test case with boundary value highlights.
4. **Granular Selective Execution**: Checkbox selection and category filter pills to execute individual or targeted batches of test cases in live desktop browser mode with screenshot captures.
