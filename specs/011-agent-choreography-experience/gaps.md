# Gaps 011: Current Vs Target

## Gap Matrix

### G1 Orchestration Surface Incomplete
- Current: Staged panels exist but not a fully unified dominant choreography surface.
- Target: Single large rounded container with clear left and right semantic lanes.

### G2 Agent Transition Motion Incomplete
- Current: Basic active card motion exists.
- Target: Deterministic hero-to-compact compression and next-agent bottom-to-center promotion.

### G3 Subagent Visibility Missing
- Current: Activity text rotates but subagent queue and state model are implicit.
- Target: Ordered subagent stream with visual state and text updates per unit of work.

### G4 Upcoming Agent Preview Weak
- Current: Next agent context is not consistently emphasized.
- Target: Persistent next-agent preview above the active flow.

### G5 Upload Summary Experience Partial
- Current: Upload data exists but interaction and filtering must be deterministic across both lanes.
- Target: Collapsed stats by default, expandable detail rows, and all or included or excluded or reviewed filters.

### G6 Retry Invalidation Determinism Missing
- Current: Previous navigation exists but downstream invalidation semantics are not fully contract-defined.
- Target: Retry previous agent purges all downstream state and dependent visual artifacts.

### G7 Frontend-Backend Lifecycle Contract Drift Risk
- Current: Status exists but event-level schema for choreography is not strict.
- Target: Structured event contract and generation semantics.

### G8 Test And Evidence Closure Incomplete
- Current: Partial behavior tests.
- Target: Coverage for choreography, subagents, upload filtering, retry invalidation, and command evidence.
