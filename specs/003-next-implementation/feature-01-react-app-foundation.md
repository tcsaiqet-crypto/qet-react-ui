# Feature 01: React App Foundation

## Goal
Create the real React application that becomes the primary UI for Home + Understanding.

## Deliverables
- new React + Vite + TypeScript app in the project folder
- basic app shell with layout and routing
- top tab bar with Home and Understanding
- disabled placeholders for later tabs
- app-wide theme and base styling

## Acceptance Criteria
1. The app boots successfully in the new project folder.
2. Home tab renders as the default entry screen.
3. Understanding tab is visible and enabled when valid intake state exists.
4. Remaining tabs are visible but disabled placeholders.

## Technical Notes
- Keep Streamlit intact as legacy compatibility.
- Initialize the React app as a separate implementation workspace.
- Build lightweight state management for the current run and UI lifecycle.
