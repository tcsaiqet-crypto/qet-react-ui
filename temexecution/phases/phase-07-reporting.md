# Phase 07 - Reporting

## Objective
Create auditable quality reports from the current generation only.

## Steps
1. Require valid upstream execution artifacts.
2. Aggregate requirements, tests, data, scripts, and outcomes.
3. Generate HTML, PDF, and JSON where configured.
4. Include provenance, timestamps, failures, and coverage.
5. Reject or remove invalidated-generation artifacts.

## Exit Gate
A report can be traced back to one run generation and its source artifacts.
