# Phase 05 - Test Generation

## Objective
Generate usable test cases and synthetic data from validated requirements.

## Steps
1. Require Understanding and, when enabled, categorization.
2. Generate positive, negative, boundary, and security-relevant cases.
3. Validate each test case has requirement traceability.
4. Generate synthetic data only for valid test inputs.
5. Validate data shape and persist provenance.

## Exit Gate
Test cases and datasets are non-empty, validated, traceable, and generation-consistent.
