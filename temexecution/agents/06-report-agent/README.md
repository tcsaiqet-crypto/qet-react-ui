# Report Agent

## Responsibility
Produce an auditable quality report from current-generation requirements, tests, data, automation, and outcomes.

## Inputs
- Valid upstream artifacts.
- Execution results and diagnostics.
- Coverage mappings.

## Outputs
- HTML report.
- PDF report when configured.
- JSON report data.
- Report provenance and summary metrics.

- `backend/src/agents/report_agent.py`
