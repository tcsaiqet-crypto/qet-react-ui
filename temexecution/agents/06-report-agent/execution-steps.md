# Report Execution Steps

1. Require current-generation upstream artifacts.
2. Gather requirements, categories, test cases, datasets, scripts, and execution results.
3. Calculate coverage and quality metrics from persisted evidence.
4. Include provider/model and stage provenance where AI was used.
5. Generate configured HTML, PDF, and JSON outputs.
6. Validate report links and artifact existence.
7. Exclude invalidated or stale-generation outputs.
8. Persist report metadata and completion event.
9. Surface report-generation failures with exact diagnostics.
10. Test missing artifact, stale generation, download, and successful report paths.
