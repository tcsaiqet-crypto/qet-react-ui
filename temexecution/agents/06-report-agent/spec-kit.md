# Report Spec-Kit Brief

## Goal
Deliver reproducible, traceable quality reports from the current run generation.

## Must Cover
- Inputs and coverage calculations.
- HTML/PDF/JSON output.
- Artifact links and downloads.
- Provenance and timestamps.
- Stale or invalidated artifact rejection.
- Report failure diagnostics.

## Acceptance
A report is generated only from valid current-generation evidence and can be traced to its run, stages, and source artifacts.
