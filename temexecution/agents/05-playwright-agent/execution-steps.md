# Playwright Execution Steps

1. Require valid test cases and synthetic data.
2. Select supported browser and execution mode.
3. Resolve selectors from source inventory and documented evidence.
4. Generate maintainable page objects/scripts.
5. Validate navigation, waits, inputs, assertions, and data references.
6. Run only when the relevant execution feature is enabled.
7. Persist scripts and execution evidence by generation.
8. Capture failure diagnostics, screenshots, traces, and logs.
9. Never convert an execution failure into a passed test.
10. Test selector absence, timeout, browser failure, and successful artifact persistence.
