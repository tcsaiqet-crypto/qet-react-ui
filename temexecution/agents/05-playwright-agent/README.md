# Playwright Agent

## Responsibility
Produce controlled browser automation from validated tests and synthetic data.

## Inputs
- Valid test suite.
- Valid synthetic dataset.
- Source/UI inventory and execution flags.

## Outputs
- Page objects or scripts.
- Execution logs, screenshots, traces, and failures.
- Test-to-script mappings.

## Code Anchors
- `backend/src/agents/playwright_agent.py`
- `backend/src/workflows/pipeline.py`
- `backend/src/config.py`
