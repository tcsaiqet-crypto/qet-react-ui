# Understanding Agent

## Responsibility
Use AI to analyze requirements and source code and produce validated application understanding.

## Inputs
- Ready intake manifest.
- Requirement document list.
- Selected provider and valid provider key.

## Outputs
- Summary and architecture notes.
- Components, flows, inventories, and gaps.
- Validation report.
- AI provenance and diagnostics.
