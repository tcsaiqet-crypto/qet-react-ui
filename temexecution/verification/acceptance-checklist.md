# Acceptance Checklist

- [ ] New run creates a persisted run state.
- [ ] Requirements and codebase uploads are independently visible.
- [ ] Understanding is blocked until intake readiness is true.
- [ ] Active provider and model are visible and accurate.
- [ ] Understanding failures show actionable diagnostics.
- [ ] Each agent starts only after its dependency is valid.
- [ ] Each agent emits a validated output or an explicit failure/block.
- [ ] Active and upcoming agents are visible.
- [ ] Subagent messages match persisted lifecycle events.
- [ ] Retry increments generation and removes downstream results.
- [ ] Refresh reconstructs the same state.
- [ ] Reports contain current-generation provenance.
- [ ] Light and dark themes remain readable.
- [ ] Frontend build and tests pass.
- [ ] Backend tests pass.
