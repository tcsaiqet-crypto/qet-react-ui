# Test Matrix

| Area | Minimum validation |
|---|---|
| Intake | Upload document, upload ZIP, invalid ZIP, incomplete readiness |
| Provider | Selected Gemini used, selected OpenAI used, missing key, rejected key |
| Understanding | Valid JSON, malformed JSON, schema failure, timeout, diagnostics |
| Categorization | Enabled path, disabled path, missing requirements |
| Test Cases | Dependency block, traceability, non-empty output |
| Test Data | Dependency block, schema validation, provenance |
| Playwright | Selector generation, execution failure, artifact persistence |
| Reporting | Current-generation report, missing artifact block, report download |
| Lifecycle | Event ordering, timestamps, restore, retry invalidation |
| Frontend | Hero transition, subagent states, filters, error visibility |
