## Part 4: Autoscroll Behavior Specification

```
TRIGGER MAP:

Event                          →  Scroll Target
─────────────────────────────────────────────────
Docs upload success            →  ZIP upload zone
ZIP upload success             →  ZIP intake progress section
ZIP intake complete            →  Understanding CTA / start button
Understanding start clicked    →  Understanding output section
Understanding complete         →  Understanding result card

GUARD RULES:
1. Each trigger fires exactly ONCE per lifecycle event
2. Track triggered state in a ref: const scrolledFor = useRef<Set<string>>(new Set())
3. Check: if (scrolledFor.current.has(eventKey)) return;
4. Then: scrolledFor.current.add(eventKey); scrollTo(target);
5. Use smooth scroll: element.scrollIntoView({ behavior: 'smooth', block: 'start' })
6. Offset: add ~80px top margin to account for fixed nav bar

IMPLEMENTATION (React):
const scrollTo = (refEl: React.RefObject<HTMLElement>) => {
  if (!refEl.current) return;
  const top = refEl.current.getBoundingClientRect().top
    + window.scrollY
    - 90; // nav height offset
  window.scrollTo({ top, behavior: 'smooth' });
};
```

## Part 5: Understanding Agent JSON Fix

### Root Cause

```
PROBLEM:
Gemini (and sometimes GPT-4o) wraps JSON in markdown fences:

```json
{
  "summary": "...",
  ...
}
```

The current parser calls json.loads() directly on the raw string.
This fails immediately because the string starts with ` ```json `
not with `{`.

SECONDARY PROBLEM:
Some responses are truncated mid-JSON when the model hits
its output token limit. This causes a partial valid structure
that json.loads() also rejects.
```

### The Fix (Three-Layer Parser)

```python
# backend/src/services/llm_service.py
# Add this function — use it everywhere json.loads is called on model output

import json
import re

def parse_model_json(raw: str, context_label: str = "model") -> dict:
    """
    Three-layer JSON parser for LLM output.
    
    Layer 1: Direct parse (clean JSON)
    Layer 2: Strip markdown fences, then parse
    Layer 3: Minimal safe repair, then parse
    Layer 4: Fail-fast with rich diagnostics
    
    NEVER returns fake/deterministic content on failure.
    ALWAYS raises ParseError with structured diagnostics.
    """
    if not raw or not raw.strip():
        raise ModelJSONParseError(
            stage="empty_response",
            raw_preview="",
            message="Model returned empty response.",
            repairable=False,
        )

    # ── Layer 1: Direct parse ─────────────────────────
    stripped = raw.strip()
    try:
        return json.loads(stripped)
    except json.JSONDecodeError:
        pass  # Continue to Layer 2

    # ── Layer 2: Strip markdown fences ───────────────
    fence_pattern = r'^```(?:json)?\s*\n?(.*?)\n?```\s*$'
    fence_match = re.match(fence_pattern, stripped, re.DOTALL | re.IGNORECASE)
    if fence_match:
        inner = fence_match.group(1).strip()
        try:
            return json.loads(inner)
        except json.JSONDecodeError:
            stripped = inner  # Use the extracted content for Layer 3

    # Also handle inline fences without newlines
    if stripped.startswith('```'):
        lines = stripped.split('\n')
        # Remove first line (```json or ```) and last line (```)
        if lines[-1].strip() == '```':
            inner = '\n'.join(lines[1:-1]).strip()
        else:
            inner = '\n'.join(lines[1:]).strip()
        try:
            return json.loads(inner)
        except json.JSONDecodeError:
            stripped = inner

    # ── Layer 3: Safe minimal repair ─────────────────
    # Only attempt repair for clearly truncated responses
    repaired = _attempt_safe_repair(stripped)
    if repaired:
        try:
            parsed = json.loads(repaired)
            # Log that repair was used (for provenance tracking)
            import logging
            logging.warning(
                f"[{context_label}] JSON repair was applied. "
                f"Original length: {len(raw)}, Repaired: {len(repaired)}"
            )
            return parsed
        except json.JSONDecodeError:
            pass

    # ── Layer 4: Fail-fast with rich diagnostics ──────
    preview = raw[:300].replace('\n', ' ').strip()
    is_truncated = _looks_truncated(stripped)

    raise ModelJSONParseError(
        stage="parse_failed",
        raw_preview=preview,
        message=(
            "Model returned response that could not be parsed as valid JSON. "
            + ("Response appears truncated (token limit likely reached). "
               if is_truncated else "")
        ),
        repairable=False,
        truncated=is_truncated,
    )


def _attempt_safe_repair(s: str) -> str | None:
    """
    Only attempt repair for truncated JSON.
    Do NOT attempt repair for structurally wrong responses.
    """
    if not _looks_truncated(s):
        return None  # Only repair truncation, not garbage

    # Count open/close braces and brackets
    open_braces = s.count('{') - s.count('}')
    open_brackets = s.count('[') - s.count(']')

    # Only repair if we just need closing chars (simple truncation)
    if open_braces < 0 or open_brackets < 0:
        return None  # Structurally inverted — not safe to repair

    if open_braces > 5 or open_brackets > 5:
        return None  # Too deeply truncated — repair would be fabrication

    # Close any open string (only if last char suggests mid-string)
    repaired = s.rstrip()
    if repaired and repaired[-1] not in ('}', ']', '"', ','):
        # Remove the dangling partial value
        last_complete = max(
            repaired.rfind(','),
            repaired.rfind('{'),
            repaired.rfind('['),
        )
        if last_complete > 0:
            repaired = repaired[:last_complete].rstrip().rstrip(',')

    # Close brackets then braces
    repaired += ']' * open_brackets
    repaired += '}' * open_braces

    return repaired


def _looks_truncated(s: str) -> bool:
    """
    Heuristic: does this look like a truncated JSON stream?
    """
    s = s.strip()
    if not s:
        return False
    last_char = s[-1]
    # Truncated responses usually end mid-string or mid-value
    return last_char not in ('}', ']')


class ModelJSONParseError(Exception):
    def __init__(
        self,
        stage: str,
        raw_preview: str,
        message: str,
        repairable: bool = False,
        truncated: bool = False,
    ):
        self.stage = stage
        self.raw_preview = raw_preview
        self.message = message
        self.repairable = repairable
        self.truncated = truncated
        super().__init__(message)
```

## Part 10: Key Rules Going Forward

```
1. NO LEFT SIDEBAR
   Ever. Navigation is top bar only.
   If a new section is needed, it goes in main content area vertically.

2. UPLOAD ZONES ARE NOT OVALS
   Border-radius is --radius-md (10px max on upload zones).
   No "curvy rectangle" shapes.

3. FILE LISTS ARE HIDDEN BY DEFAULT
   Default state = count only.
   User must click expand to see file names.

4. AUTOSCROLL FIRES ONCE
   Each lifecycle event triggers scroll exactly once.
   useRef guard prevents re-trigger.

5. JSON PARSER NEVER FABRICATES
   If fence-stripped + repair still fails → structured error.
   No fake content. No silent success.

6. COLORS FROM TOKENS ONLY
   No inline hex values in components.
   No global * overrides in CSS.
   All colors via var(--token-name).

7. PROVIDER SWITCH IS COMPACT
   ~140px width. Small pill toggle.
   Not a full button row taking up nav space.

8. TIMELINE IS ALWAYS VISIBLE
   It does not hide after a step completes.
   It is the user's orientation anchor throughout the flow.
```
